# Security and responsible reporting

This repository contains public documentation and published architecture drawings, not engine binaries, private code, broker tokens, customer records or live market data.

Do not post potential vulnerabilities, credentials or confidential market-data material in public GitHub issues. Report sensitive security concerns privately to contact@aionanalytics.in with a clear subject and minimal reproducible information. Do not attempt testing of live trading, customer systems or private endpoints without written permission.

No production service availability, security certification or bug bounty authorization is implied by this repository.
